# Политики компании

Один файл `.md` = одна политика; имя файла = `slug.md`.
Front matter: `title`, `slug`, `team`, `summary` (все строки, slug в kebab-case).
Тело — Markdown после `---`; пишите кратко, списки и заголовки `##`.
Новую политику добавляйте сюда — модуль `src/lib/policies.ts` подхватит при сборке.
